# Before making the repository public

- Confirm you are allowed to publish the project name, logo and visual assets.
- Confirm team-authored frontend files may be redistributed, or replace them with your own reconstruction.
- Keep the wording “team project” and state your approximate frontend contribution rather than implying sole authorship.
- Do not add the original backend repository, production `.env`, database dumps, API keys, OAuth secrets or deployment credentials.
- Replace any real user/professor data with synthetic/demo data.
- Add 3–5 screenshots or a short GIF after deploying the demo.
- Link the live demo in the GitHub repository description.
- Pin this repository only after the README clearly explains the private-project/public-reconstruction relationship.
