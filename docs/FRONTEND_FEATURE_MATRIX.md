# Frontend Feature Matrix

| Area | Frontend behavior represented | Public demo status |
|---|---|---|
| Authentication | Login, signup, OTP, forgot/reset password, token storage, protected routes | Mocked locally |
| Dashboard | Overview cards, quick stats, profile/resources/plans/history/favorites entry points | UI available |
| Search | Professor/university modes, metadata-driven filters, sorting, pagination response model | Synthetic dataset |
| Professor details | Stats, tags, links, highlights, biography, article carousel | Synthetic dataset |
| Profile | Basics, education, experience, outputs, credentials, skills, links, languages, interests, extras | Local CRUD |
| Resume list | Card/table views, status, completeness, rename/duplicate/delete | Local CRUD |
| Resume from profile | Select profile sections and create a resume | Mocked locally |
| Resume from scratch | Structured sections with completeness calculation and autosave-oriented behavior | Mocked locally |
| Resume design | Editable preview, section mapping/order, print/export and LaTeX generation logic | Frontend logic retained |
| Resume import | PDF/DOCX entry screen | Coming Soon in supplied UI |
| Email & SOP | Create/edit rich-text documents, local persistence, duplicate/delete | Browser-local |
| Notifications | List, read/unread grouping, mark read, detail route | Mocked locally |
| FAQ / Chat | FAQ topics plus guest/session service contracts | Deterministic local replies |
| Subscription | Pricing/plan UI | UI only |
| Stats/Favorites/History/Settings | Navigation routes | Placeholder screens |
| Landing | Marketing page with responsive navigation and CTAs | Included |
