# Resume / Portfolio Copy

## Short project description

**Profejoo — Academic Productivity Platform**  
A private 6-person team project for professor/university discovery, academic profile management, resume creation, outreach documents, and student application workflows. I implemented roughly **80% of the frontend**. This public repository is a sanitized portfolio reconstruction with mocked data and no private backend code.

The production repository is private because it was a collaborative project. Instead of publishing the backend or internal infrastructure, I created a public reconstruction that preserves the frontend architecture and user flows. API contracts are replaced with a local mock adapter, so recruiters can clone the repository and explore the UI without access to private services or data.
